# Security Policy

## Report a vulnerability privately

Use GitHub's [Report a vulnerability](https://github.com/zeropress-app/zeropress-static/security/advisories/new)
form, available under **Security → Report a vulnerability**.

Keep exploit code, credentials, access tokens and personal data out of public
posts. Use installations and test data you control.

## What to include in a private report

- The plugin, WordPress and PHP versions.
- The affected feature and configuration needed to reproduce the issue.
- Reproduction steps, the observed result and potential impact.
- Relevant logs or screenshots with secrets and personal data removed.

Coordinate public disclosure with the maintainers so users can receive a fix or
mitigation before reproduction details become public.
